# Асинхронное тестирование FastAPI-приложения

## Описание проекта

Проект представляет собой пример автоматизированного тестирования REST API веб-приложения, которое позволяет пользователям регистрироваться, авторизоваться, просматривать и редактировать свой профиль.

В рамках проекта реализовано API на FastAPI и написаны асинхронные автоматизированные тесты с использованием pytest и httpx.

## Используемые технологии

- **Python** — язык программирования.
- **FastAPI** — фреймворк для разработки API.
- **pytest** — фреймворк для автоматизированного тестирования.
- **pytest-asyncio** — поддержка асинхронных тестов.
- **httpx** — библиотека для отправки асинхронных HTTP-запросов.
- **Pydantic** — проверка и валидация входных данных.

## Реализованные тестовые сценарии

### Регистрация пользователя
- Успешная регистрация.
- Регистрация с уже существующим именем пользователя.
- Проверка некорректного email.
- Проверка слишком короткого пароля.

### Авторизация
- Успешный вход в систему.
- Вход с неправильным паролем.
- Вход несуществующего пользователя.

### Просмотр профиля
- Получение профиля авторизованного пользователя.
- Попытка доступа без токена авторизации.
- Попытка доступа с недействительным токеном.

### Редактирование профиля
- Успешное изменение данных профиля.
- Попытка редактирования без авторизации.
- Попытка сохранения некорректного email.

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/sativo4ka/async-fastapi-test-project.git
cd async-fastapi-test-project
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация виртуального окружения

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Запуск тестов

```bash
python -m pytest -v
```

## Асинхронное тестирование

В проекте используются:

- `async def` для создания асинхронных тестовых функций.
- `await` для выполнения асинхронных HTTP-запросов.
- `httpx.AsyncClient` для взаимодействия с API.
- `pytest.mark.asyncio` для запуска асинхронных тестов.
- фикстуры pytest для подготовки тестового окружения.
